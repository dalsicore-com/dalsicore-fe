Dalsilens — Visual Aid
for Dichromacy

A research project exploring how software can assist individuals with dichromacy (a form of color vision deficiency) in perceiving and distinguishing colors. Dalsilens investigates real-time image processing techniques to remap color information in a way that aligns with how dichromatic users see the world.
