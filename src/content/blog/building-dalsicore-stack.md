Running a solo product-and-research studio forces prioritization. Every decision in the stack has to reduce complexity while preserving room for experimentation.

## Core principles

1. Native first when product responsiveness matters.
2. Keep architecture explicit and boring where possible.
3. Reserve complexity for features that genuinely need it.

## Tooling baseline

Dalsicore products currently center around Kotlin, Jetpack Compose, and pragmatic local-first data patterns. This keeps development velocity high while giving full control over UX and performance.
